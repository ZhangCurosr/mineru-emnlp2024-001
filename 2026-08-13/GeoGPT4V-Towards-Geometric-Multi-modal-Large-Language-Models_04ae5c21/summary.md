# 论文速读：GeoGPT4V: Towards Geometric Multi-modal Large Language Models with Geometric Image Generation

## 一句话总结
本文提出一种自动化的几何数据生成流水线，利用 GPT-4V 和 GPT-4 生成**难度较低、图文高度对齐**的几何题目与对应图像，构建 GeoGPT4V 数据集。实验证明，该数据集能显著提升各类多模态大语言模型（MLLM）在几何问题求解上的性能。

## 研究问题与动机
1.  **多模态模型的几何能力不足**：几何问题通常依赖视觉辅助，即使最先进的 MLLM（如 GPT-4V、Gemini）在此类任务上仍显著落后于人类。
2.  **高质量几何训练数据匮乏**：现有开源几何数据集（如 UniGEO）的题目对模型学习基础几何概念而言**过于困难**，缺乏渐进性。
3.  **图文对齐问题突出**：现有的数据增强方法（如使用 ChatGPT-3.5 仅修改文本中的数值）容易导致**文本与图像不匹配**，干扰模型学习。

## 核心贡献（创新点）
1.  **首个图文对齐的自动化几何数据生成流水线**：与仅修改文本数据的 G-LLaVA 等方法不同，本文通过“简化问题 → 代码生成图像 → 图文对齐评分过滤”的完整闭环，确保生成数据“简单易懂且图文一致”。
2.  **提出由难到易的课程学习数据构建策略**：利用 GPT-4V 对原始难题进行简化，生成子问题或引导性问题，构建难度梯度，更利于模型学习基础几何概念。
3.  **构建并发布高质量混合数据集 GeoGPT4V**：将 4.9K 条自动生成的高质量数据与 19K 开源数据混合，为社区提供了一个难度分布合理、图文对齐的几何基准。
4.  **系统验证了生成图像与评分过滤的有效性**：通过消融实验证明，新生成的图像比简单替换原始图像更有效，而基于 GPT-4V 的 Chain-of-Thought 评分过滤是保证图像质量的关键。

## 方法详解
整个流水线分为三个核心步骤：

1.  **问题-答案对生成（简化与多元化）**：
    *   输入：开源数据集 $D = \{Q, A, I\}$（问题、答案、原始图像）。
    *   使用 **GPT-4V** 根据原始 QA 对生成简化版本 $\tilde{Q}, \tilde{A}$。指示 GPT-4V 从三个视角生成：(1) 前置引导问题；(2) 分解的子问题；(3) 将结论转化为条件以降低复杂度。同时要求生成多样的问题并附带图像描述 $\tilde{Des}$。
    *   输出：$\tilde{D}_1 = \{\tilde{Q}, \tilde{A}, \tilde{Des}\}$。每个原始数据点生成 $N=3$ 个新数据点。

2.  **几何图像生成**：
    *   输入：$\tilde{D}_1$ 中的 $\tilde{Q}, \tilde{A}, \tilde{Des}$。
    *   使用 **GPT-4** 根据提示生成可执行的 **Wolfram 代码**。为提升代码正确率，每个 QA 对生成 $K=3$ 份不同的代码，并执行得到 $K$ 张候选图像 $\tilde{I}^{(1)}, ..., \tilde{I}^{(K)}$。
    *   输出：$\tilde{D}_2 = \{\tilde{Q}, \tilde{A}, \tilde{I}^{(1)}, ..., \tilde{I}^{(K)}\}$。

3.  **图文对齐评分与筛选**：
    *   使用 **GPT-4V** 对每对 $(\tilde{Q}, \tilde{I}^{(i)})$ 进行评分（0-1 分），**并强制其先输出评分理由（Chain-of-Thought）** 再给出最终分数，以提升评分准确性。
    *   为每个问题保留得分最高的图像 $\tilde{I}$。若最高分低于 0.9，则丢弃该样本。
    *   最终输出：$\tilde{D} = \{\tilde{Q}, \tilde{A}, \tilde{I}\}$，即简化且图文对齐的几何数据集。

## 实验与结果
*   **数据集**：GeoGPT4V 由 4.9K 生成数据与 19K 开源数据（ChartQA, UniGEO-Calculation, Geometry3K, GeoQA+ 等）混合而成（见表 1）。
*   **评估基准**：MathVista testmini 和 MathVision test。
*   **基线模型**：LLaVA-1.5 (7B/13B), ShareGPT4V (7B/13B), InternVL-Chat-V1.2-Plus (40B)。
*   **主要结果**：
    *   所有模型在几何相关任务上均有显著提升。例如，**LLaVA-1.5-7B** 在 MathVista 的 **GPS（几何问题求解）minitest** 上从 20.67 提升至 **32.69**（相对提升 **58.2%**）；**ShareGPT4V-7B** 从 21.63 提升至 **32.69**（相对提升 **33.8%**）（表 2）。
    *   **InternVL-Chat-V1.2-Plus-G** 在 MathVista GPS 和 GEO 任务上均达到开源模型最高分（64.42 和 63.60）。
*   **消融实验**：
    *   **生成图像 vs 原始图像**：使用新生成图像的模型性能显著优于使用原始图像仅替换文本的模型（表 3）。
    *   **评分过滤 vs 随机选择**：使用 GPT-4V 评分选出的图像优于随机选择的图像（表 3）。
    *   **生成数据 vs 纯开源数据**：仅用生成数据替换（Replace）或混合（Mix）开源数据，均比纯开源基线（Base）效果更好，证明生成数据本身的高质量与有效性（表 5）。

## 相关工作脉络
1.  **G-LLaVA**：同样关注几何多模态学习，但其数据增强仅通过 ChatGPT-3.5 修改文本数值，**缺乏对应图像的同步生成与对齐**，导致图文可能不匹配。
2.  **UniGEO**：构建的高难度几何数据集，包含证明与计算任务，但**题目难度过高**，不利于直接用于 MLLM 的几何基础能力训练。
3.  **LLaVA / ShareGPT4V**：通用多模态大模型的代表性工作，通过高质量图文对话数据微调提升通用能力，但**在专业几何数学推理上表现仍有局限**。
4.  **MathVista / MathVision**：当前主流的多模态数学推理评测基准，本文选用它们作为核心评估标准。

## 局限性与未来方向
1.  **图像生成方法不稳定**：依赖 GPT-4 生成 Wolfram 代码来制图，成功率并非 100%，且可能产生低质量图像，导致需要额外的 GPT-4V 评分过滤，**增加了 API 调用成本**。
2.  **仅聚焦于“简化”问题**：目前工作仅限于生成更基础的几何题，**尚未探索如何生成更复杂的几何问题**以进一步提升模型的复杂推理能力。
3.  **任务范围有限**： multimodal math 不仅限于几何，还包括图表问答、函数图像等，**丰富的图表和函数图像生成是未来的重要方向**。

## 研究启发与可借鉴点
1.  **课程学习思想的数据构建**：对于模型能力薄弱且数据困难的领域，**由 GPT 将难题拆解、简化为循序渐进的子问题**是一种有效的数据增强策略。
2.  **“代码生成图像”作为图文对齐的可靠方案**：对于需要精确视觉表达的领域（如几何、图表、公式），利用大模型生成**可执行代码（如 Wolfram、Matplotlib）来合成图像**，比单纯让视觉模型绘图更可控、对齐度更高。
3.  **CoT 评分用于数据过滤**：利用 VLM 进行**带推理链的打分（Chain-of-Thought Scoring）** 来自动化评估和筛选合成数据的质量，是一条可扩展且有效的方法论。
4.  **开源数据与合成数据的混合策略**：将高质量、特定领域的合成数据与大规模、多样化的开源数据混合训练，可以在提升专项能力的同时保持模型的通用性。

## 关键术语表
**MLLM (Multi-modal Large Language Model)**：多模态大语言模型，能够同时处理和理解文本、图像等多种模态输入的大规模语言模型。
**GeoGPT4V**：本文提出的几何多模态数据集及基于此训练的模型系列名称。
**Wolfram Code**：指 Wolfram Language/Mathematica 代码，本文用它来程序化地生成准确的几何图形。
**Chain-of-Thought (CoT) Prompting**：思维链提示，通过在提示中要求模型分步推理，以激发其复杂问题解决能力。本文用于 GPT-4V 的评分环节。
**GPS (Geometry Problem Solving)**：几何问题求解，MathVista 基准中的一个核心评估任务。
**GEO (Geometry Reasoning)**：几何推理，另一项核心的几何能力评估任务。

## 可复现要素
*   **数据集**：GeoGPT4V 已开源，包含 4.9K 条生成数据及 19K 混合数据。开源链接见论文。
*   **代码**：项目代码已开源（https://github.com/Lanyu0303/GeoGPT4V_Project）。
*   **模型权重**：在 GeoGPT4V 上微调的各规模模型 checkpoint 已开源。
*   **关键超参**：每个原始样本生成 $N=3$ 个新问题；每个问题生成 $K=3$ 份 Wolfram 代码；评分阈值设为 0.9；训练 1 个 epoch，batch size 128，learning rate $2e-5$（LLaVA/ShareGPT4V）或 $1e-5$（InternVL）。
