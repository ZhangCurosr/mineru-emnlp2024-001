# 论文速读：QUITE-Quantifying-Uncertainty-in-Natural-Language-Text-in-Ba

## 一句话总结
本文提出了 **QUITE**，一个用于量化自然语言文本中不确定性的贝叶斯推理问答数据集，包含真实世界的因果网络、分类随机变量及两种前提表述（显式数值概率与估算概率词）。实验表明，通过微调将 LLM 作为语义解析器输出 **ProbLog** 程序的神经符号方法，在所有推理类型（因果、证据、解释排除）上均显著优于纯 LLM 提示方法。

## 研究问题与动机
1. **核心问题**：如何评估大语言模型（LLMs）在自然语言描述的贝叶斯推理场景中的定量不确定性推理能力？
2. **现有方法不足**：
   - 现有基准（如 CLADDER、BLInD）通常仅使用**二元随机变量**、基于**模板生成**相对简单的文本，且问题多为是/否判断题或排序题，无法衡量模型输出与真实概率值的相关性。
   - LLMs 在零样本或 CoT 提示下，于高阶因果网络上的贝叶斯推断性能甚至不优于随机基线，且在**反向推理**（证据推理、解释排除）任务上存在系统性失败。
   - 缺乏在**分类变量**（非二元）和**多样化自然语言表述**（含估算概率词 WEPs）下评估复杂贝叶斯推理的基准。

## 核心贡献（创新点）
1. **提出 QUITE 数据集**：首次构建包含真实世界域（医学、气象、保险等）的贝叶斯网络自然语言化数据集，支持**分类随机变量**与三种贝叶斯推理类型（因果、证据、解释排除），并要求输出细粒度的数值概率估计。
2. **引入估算概率词（WEPs）前提**：除显式数值概率前提外，还构建了一版将概率替换为自然语言估算词（如"unlikely""highly likely"）的前提，模拟人类对话风格的不确定性表达。
3. **端到端神经符号微调范式**：不同于先前工作仅用提示让 LLM 生成符号表示，本文**首次明确微调** SOTA LLM（Mistral-7B）进行自然语言到概率逻辑编程语言 **ProbLog** 的语义解析，并将解析结果交由外部求解器计算答案。
4. **系统揭示 LLMs 在贝叶斯推理中的能力边界**：实验证明，所有测试的 LLMs（包括 GPT-4）在证据推理和解释排除任务上，零样本和 CoT 提示均表现极差；而神经符号方法能稳定完成所有推理类型，证明神经符号结合是提升复杂推理的有效方向。

## 方法详解
1. **数据集构建**：
   - **网络来源**：从公开库（bnlearn、BNMA）选取多个真实贝叶斯网络，对于大型网络，通过边际化根节点生成自包含的子网络（共30个子网络）。
   - **前提生成**：对每个条件概率表（CPT）条目，使用 LLM（Mixtral-8x7B）将模板 `If [Conditions], then [Probabilities]` 转化为多样化的自然语言句子。数值概率版直接表述百分比；WEP 版依据 Fagen-Ulmschneider (2015) 的人类调查，将数值映射到最接近的估算概率副词（如 0.2→probably not, 0.02→almost no chance）。
   - **问题-证据对生成**：随机采样1至 n-1 个变量的观测值作为证据，并选择一个目标变量提问。Ground truth 概率由底层贝叶斯网络精确计算得出。问题按推理类型分类：若观察到某节点的父节点则为**因果推理**；观察到子节点则为**证据推理**；观察到某节点的子节点及其另一个父节点则为**解释排除**。
   - **符号表示**：将前提和 QE 对手动定义谓词后，通过规则转换为 **ProbLog** 程序（支持带注解的选择析取以处理分类变量）。
2. **模型与方法**：
   - **LLM 提示基线**：零样本直接问答、CAUSALCOT（要求模型逐步构建概率图、提取问题类型并进行数学计算）。
   - **神经符号方法（ProbLog-FT）**：使用微调后的 Mistral-7B 作为语义解析器，将自然语言前提、证据和查询解析为 ProbLog 程序；首先生成前提的概率逻辑表示（确定谓词词汇表），再解析 QE 对。解析后的 ProbLog 程序由专用求解器执行，输出最终概率。
   - **其他基线**：50% 随机猜测、仅 QE 无前提（GPT-4-Turbo）、回归微调（Llama2-7B）、直接预测概率文本的 LLM 微调（Mistral-7B）。
3. **微调细节**：使用 LoRA（rank=64, α=32）在 H100/A100 GPU 上进行全精度（FP32）微调，学习率 5e-5，batch size=4，ProbLog-FT 训练12个 epoch。

## 实验与结果
- **数据集规模**：训练集20个网络，测试集10个网络。数值和 WEP 版前提各1192条，QE 对测试集共230个（92因果、62证据、26解释排除）。平均每个随机变量有3.3个状态，每个网络平均5.9个随机变量。
- **评估指标**：准确率（prediction correct）、错误率、无效输出率、RMSE（含两种变体：无效输出fallback为50%的 RMSE_50%、以及仅有效输出的 RMSE_nonError）。
- **数值前提主要结果**（Table 4 上部分）：
  - **ProbLog-FT**（Mistral-7B 微调）表现最佳：**准确率54.5%**，RMSE_50% 为 **0.244**，显著优于所有提示方法和微调基线。
  - GPT-4-Turbo 零样本准确率 36.7%，CAUSALCOT 提升至 37.1%；Llama-3-8B 和 Mixtral-8x7B 性能较低。
  - 仅 QE 无前提的 GPT-4 基线准确率仅 3.1%，证明任务需要推理而非依赖预训练知识。
- **WEP 前提结果**：Problog-FT 准确率降至 1.3%（因解析错误增加），但其 RMSE_50% (0.319) 仍与 GPT-4-Turbo (0.341) 相当甚至更优，表明微调的神经符号方法在小参数下能与大参数 LLM 竞争。
- **推理类型分析**（Figure 1）：因果推理对所有模型相对容易；但**所有 LLMs 在证据推理和解释排除上几乎完全失败**（准确率接近0%），而 **ProbLog-FT 在三类推理上均保持稳健性能**。
- **最强结果**：ProbLog-FT oracle（给定正确前提解析，仅微调 QE 解析）准确率达 **87.3%**，RMSE_nonError 低至 **0.145**，证明性能瓶颈主要在**长前提序列的语义解析**而非符号推理本身。

## 相关工作脉络
1. **CLADDER** (Jin et al., 2023)：评估 LLMs 因果推理能力的基准，但仅使用二元变量、模板化文本和是/否问题，停留在因果推断阶梯的第一层（关联）。本文扩展至分类变量、定量概率输出和多样化语言。
2. **BLInD** (Nafar et al., 2024)：聚焦 GPT 模型的数值贝叶斯推理，使用虚拟事件（如"orange event"）和模板描述。本文使用真实世界网络和非模板化自然语言，验证了神经符号方法在更真实场景下的可扩展性。
3. **ProbLog 神经符号解析**：此前工作（如 Nafar et al.）仅通过 prompt 让 LLM 生成 ProbLog 代码，解析错误率高达~76%。本文**首次明确微调** LLM 进行文本到 ProbLog 的语义解析，大幅降低解析错误。
4. **估算概率词（WEPs）建模**：既往研究（如 Sileo & Moens, 2023）主要在自然语言推理（NLI）任务中研究 WEPs。本文将其整合进贝叶斯推理基准，创建了对比设置，探索语言不确定性对推理的影响。
5. **因果推理基准**：相较于仅关注因果发现或结构学习的基准，QUITE 专注于**推理能力评估**，并区分三种不同的推理路径，提供了更细粒度的诊断。

## 局限性与未来方向
1. **推理阶梯限制**：当前 QUITE 仅覆盖 Pearl 因果推断阶梯的**第一层（关联/观察）**，尚未包含干预性查询（do-运算符，第二层）和反事实推理（第三层）。
2. **现实世界假设简化**：数据集假设完整的条件概率分布已知，但现实场景中概率分布可能未指定或存在隐藏变量。
3. **上下文长度限制**：模型一次性处理的前提数量有限，而真实文本中的不确定性描述可能分散在更长文档中，并包含无关信息。
4. **数据污染风险**：部分网络源自已发表文献，LLMs 可能在预训练中接触过相似的概率表，尽管 QE-only 低准确率表明这并非主要问题。
5. **WEP 映射的边界情况**：当分类变量的所有状态概率均较低时，基于启发式的 WEP 映射可能产生不自然的表述，需人工修正。

## 研究启发与可借鉴点
1. **神经符号微调范式**：将 LLM 微培养为特定领域逻辑语言（如 ProbLog、Datalog）的**语义解析器**，而非依赖零样本生成，可显著提升结构化推理任务的可靠性与准确性。这一模式可迁移至其他需要结合语言理解与形式化计算的领域（如规划、合规检查）。
2. **推理类型细粒度分析**：在基准中明确区分并统计不同推理模式（前向/后向、解释排除）的表现，有助于精准诊断模型的能力短板，指导后续架构或训练策略设计。
3. **WEPs 作为不确定性桥梁**：在 NLP 基准中引入从数值概率到自然语言估算词的映射，可更好地评估模型处理人类模糊表达的能力，并为多模态/多语言不确定性传播研究提供素材。
4. **长文本解析瓶颈诊断**：通过 Oracle 实验隔离解析错误源（前提解析 vs. 查询解析），指出当前神经符号系统的瓶颈在于**长上下文中的谓词一致性维护**，未来可研究分阶段解析、约束解码或外部记忆机制。
5. **真实世界网络的价值**：从标准库（如 bnlearn）选取经过社区验证的真实贝叶斯网络，能确保场景的合理性与挑战性，避免玩具网络带来的评估偏差。

## 关键术语表
- **QUITE**：Quantifying Uncertainty in Natural language Text in Bayesian reasoning scenarios，本文提出的用于评估贝叶斯推理中不确定性量化的问答数据集。
- **Words of Estimative Probability (WEPs)**：估算概率词，如 likely、unlikely、improbable 等自然语言副词，用于代替具体数值表达不确定性程度。
- **ProbLog**：概率逻辑编程语言，将概率分布嵌入一阶逻辑规则中，支持基于逻辑推理的概率计算。
- **Causal Inference**：因果推理，从原因观察推导结果概率的推理方向（前向）。
- **Evidential Reasoning**：证据推理，从结果观察反推原因概率的推理方向（后向）。
- **Explaining-away**：解释排除推理，在共同效应结构中，当一个原因被证实时，削弱其他可能原因的概率。
- **Conditional Probability Table (CPT)**：条件概率表，描述贝叶斯网络中每个节点在其父节点取值组合下的条件概率分布。
- **Neuro-symbolic Approach**：神经符号方法，结合神经网络（感知/语言理解）与符号系统（逻辑/推理）的混合 AI 范式。
