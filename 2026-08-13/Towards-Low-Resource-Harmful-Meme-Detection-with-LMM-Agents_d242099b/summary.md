# 论文速读：Towards-Low-Resource-Harmful-Meme-Detection-with-LMM-Agents

## 一句话总结
本文提出了一种基于大语言模型（LMM）的**无梯度、智能体驱动**的低资源有害模因检测框架 **LOREHM**，通过"向外检索辅助标签"与"向内反思失败案例提取洞见"的双重策略，在仅 50 条标注样本的少样本设置下显著超越现有基线方法。

## 研究问题与动机
1. **低资源场景下的检测困境**：互联网模因具有动态演化特性，新兴事件（如疫情、政治事件）相关的有害模因迅速涌现，难以快速积累足够标注数据以训练传统数据驱动模型。
2. **现有方法的局限**：既有方法（如 PromptHate、MR.HARM、Mod-HATE）依赖大量标注数据进行微调或 LoRA 适配，在少样本场景下性能受限；且传统 ICL 方式需反复拼接少量示例，推理开销巨大。
3. **隐性危害难以捕捉**：有害模因往往通过图像与文字的复杂组合传递隐含的偏见、嘲讽或误导性信息，LMM 仅凭表面模态难以准确识别。
4. **缺乏真实反馈环境**：与可交互环境的智能体任务不同，模因检测没有实时反馈机制，无法直接套用 Reflexion 等基于环境信号自我修正的方法。

## 核心贡献（创新点）
1. **首个无梯度视角的低资源有害模因检测方案**：不更新模型参数，以 LMM 作为智能体，通过推理流程而非梯度下降实现知识利用，与 Mod-HATE（LoRA 微调）形成本质区别。
2. **"向外"相对样本增强（RSA）策略**：通过多模态嵌入检索 Top-K 相似参考模因，以多数投票生成初步预测作为先验信号，区别于直接拼接 few-shot 示例的 ICL 做法，降低了推理开销并提供了显式辅助。
3. **"向内"模因洞见增强（MIA）策略**：让 LMM 在参考集上进行 zero-shot 推理，收集错误轨迹构成反思集，并通过迭代 ADD/DOWNVOTE/UPVOTE/EDIT 操作构建通用洞见解集 $\mathcal{E}_n$，区别于依赖环境反馈的 self-reflection 方法。
4. **双重策略的正交互补性验证**：消融实验证明 RSA 与 MIA 各自独立有效且结合后取得更高性能，且框架可无缝适配开放/闭源 LMM（LLaVA-34B、GPT-4o）。

## 方法详解
整体框架分为三个模块：

**（1）多模态嵌入表示**
对每个模因 $M = \{\mathcal{I}, \mathcal{T}, y\}$，使用冻结的 CLIP 视觉编码器 $\mathrm{VE}(\cdot)$ 和文本编码器 $\mathrm{TE}(\cdot)$ 计算融合嵌入：
$$Emb = \alpha \cdot \mathrm{VE}(\mathcal{I}) + \beta \cdot \mathrm{TE}(\mathcal{T}), \quad \alpha=0.2, \beta=0.8$$

**（2）向外分析 — 相对样本增强（RSA）**
- **检索**：计算目标测试模因 $M_{\text{test}}$ 与参考集 $S_{\text{ref}}$ 中每个样本 $M_{\text{ref}}$ 的余弦相似度，选取 Top-K（K=5）个最相似模因构成集合 $\mathcal{H}$。
- **投票**：对 $\mathcal{H}$ 中的标注标签进行多数投票，得到初步预测 $\mathcal{P}$：若有害标签数 $> K/2$，则 $\mathcal{P}=$ harmful，否则 $\mathcal{P}=$ harmless。
- 投票机制在 HarM/FHM/MAMI 上的 Macro-F1 约为 79%/59%/70%。

**（3）向内分析 — 模因洞见增强（MIA）**
- **经验收集**：对参考集 $S_{\text{ref}}$（N=50）中的每个模因，以 CoT 提示进行 zero-shot 推理，得到轨迹 $\text{traj}$；将推理结果与真实标签不一致的轨迹收集为反思集 $R_{\text{set}}$。
- **洞见提取**：迭代处理 $R_{\text{set}}$ 中的每条错误轨迹，以 $X_{\text{Reflect}}$ 提示引导 LMM 对当前洞见解集 $\mathcal{E}_{i-1}$ 执行四种操作之一：**ADD**（新增）、**DOWNVOTE**（降权）、**UPVOTE**（升权）、**EDIT**（编辑），更新为 $\mathcal{E}_i = \mathcal{O}_i(\mathcal{E}_{i-1})$。最终得到洞见解集 $\mathcal{E}_n$（容量上限设为 10）。

**（4）推理阶段**
结合初步预测 $\mathcal{P}$（作为先验）和洞见解集 $\mathcal{E}_n$，以最终提示模板对测试模因做出判断：
$$p_{\text{final}} = \mathrm{LMM}(X_{\text{CoT}}, \mathcal{I}_{\text{test}}, \mathcal{T}_{\text{test}}, \mathcal{P}, \mathcal{E}_n)$$
其中提示明确告知智能体分类器的初步判定，并要求其充分论证是否认同该判断。

## 实验与结果
**数据集**：HarM（COVID-19 相关，合并为二分类）、FHM（Facebook 仇恨言论挑战）、MAMI（针对女性的冒犯性模因），各数据集测试集详见论文表 3。

**评估指标**：Accuracy 与 Macro-F1（主要指标），采用 5 个不同随机种子生成的 50-shot 参考集取平均。

**主要结果**（Table 1）：

| 模型 | HarM Acc / F1 | FHM Acc / F1 | MAMI Acc / F1 |
|------|--------------|-------------|---------------|
| GPT-4o (50-shot ICL) | 71.75 / 70.23 | 66.60 / 65.74 | 80.80 / 80.52 |
| **LoREHM (GPT-4o)** | **74.57 / 72.98** | **70.20 / 70.14** | **83.00 / 82.98** |
| LLaVA-34B (50-shot ICL) | 67.80 / 62.60 | 63.80 / 63.74 | 74.60 / 74.52 |
| **LoREHM (LLaVA-34B)** | **73.73 / 70.86** | **65.60 / 65.59** | **75.40 / 75.28** |

- LOREHM（GPT-4o）较 GPT-4o 的 50-shot ICL 在 HarM/FHM/MAMI 上 Macro-F1 分别提升 **2.75%/4.40%/2.46%**。
- 消融实验（Table 2）显示：RSA 和 MIA 单独使用均可超越 50-shot ICL，两者结合效果最佳，证明策略互补而非简单叠加。
- 参考集大小 N 增加时性能趋于饱和甚至下降，说明单纯堆数据在少样本框架下效果有限。

## 相关工作脉络
1. **PromptHate / Pro-Cap（Cao et al., 2022, 2023）**：基于 prompt 学习的 multimodal 检测方法，依赖预训练的 VLM 生成图片描述后拼接文本，属于数据驱动的 prompt 适配范式，与本文无梯度智能体思路不同。
2. **MR.HARM（Lin et al., 2023a）**：从 LLM 蒸馏多模态推理知识用于有害模因检测，仍需要预训练和知识蒸馏过程；本文不修改模型参数，完全通过推理流程增强。
3. **Mod-HATE（Cao et al., 2024）**：采用 LoRA 微调进行少样本有害模因检测，依赖梯度更新；本文是 gradient-free 的替代方案，避免了微调带来的过拟合风险。
4. **LLaVA / OpenFlamingo（Liu et al., 2023a; Awadalla et al., 2023）**：通用多模态大模型，作为本文的 backbone 智能体；本文聚焦于如何更好地"使用"而非"训练"这些模型。
5. **Reflexion（Shinn et al., 2024）/ ExpeL（Zhao et al., 2024）**：依赖环境真实反馈的 self-reflection 方法，无法直接应用于无反馈的二分类模因检测任务；本文 MIA 策略是针对此场景特化设计的知识修订机制。
6. **GPT-4o / LLaVA-34B（OpenAI, 2023; Liu et al., 2023a）**：代表当前闭源/开源 LMM 的最先进水平，本文验证了 agentic 框架的可迁移性，不局限于特定模型。

## 局限性与未来方向
1. **洞察质量难以量化评估**：MIA 提取的洞见解集缺乏系统性的客观评估标准，目前只能定性分析。
2. **标注噪声的鲁棒性待验证**：数据集中存在少量争议性标注，虽然 MIA 在理论上能缓解，但在更极端的噪声场景下仍需验证。
3. **零样本设定尚未探索**：本文聚焦 50-shot 少样本，零样本场景是更严峻的低资源挑战，未来计划扩展。
4. **跨模态/跨语言泛化有限**：当前仅评测英文模因数据集，代码混合（code-mixed）数据及非英语模因的检测能力未知。
5. **计算开销较大**：基于 GPT-4o 的 MAMI 评测耗时约 2 小时，LLaVA-34B 则达 6 小时，在实际部署中需权衡效率。
6. **潜在偏见问题**：错误分析显示框架对宗教主题模因存在偏见（将某些有害宗教梗误判为无害），反映了 LMM 本身的内嵌偏差。

## 研究启发与可借鉴点
1. **无梯度智能体范式可迁移**：在数据稀缺、标注成本高的多模态分类任务中，以 LMM 为 agent 通过推理流程而非参数更新利用知识，是一条可行且高效的技术路线，可推广至虚假信息检测、违规内容审核等方向。
2. **"向外检索+向内反思"的双通道增强设计**：将外部检索辅助信号（投票先验）与内部知识修订（错误轨迹反思）解耦为正交模块，既保留了显式监督信息，又挖掘了隐式规律，此设计可复用于其他少样本多模态理解任务。
3. **基于错误轨迹的知识蒸馏思想**：与 MR.HARM 的"知识蒸馏"相比，本文的 MIA 策略直接让 LMM 自我反思错误案例，避免了对 LLM 的依赖，降低了系统复杂度，对团队既有研究有直接参考价值。
4. **CoT 输出作为可解释性工具**：框架天然产生自然语言推理链（Thought），可为人工审核员提供可追溯的判断依据，这一特性在需要解释性的内容安全场景中具有重要实用价值。
5. **参考集选择策略启示**：消融实验表明 N 过大反而性能下降，提示在少样本设置中应注重样本质量与多样性而非数量，可启发后续对参考集构建策略的研究。

## 关键术语表
**LOREHM**：Low-Resource Harmful Meme Detection 的缩写，本文提出的无梯度智能体驱动框架。
**LMM (Large Multimodal Model)**：大语言-视觉多模态模型，如 LLaVA、GPT-4o，具备同时理解和生成图像与文本的能力。
**RSA (Relative Sample Augmentation)**：向外分析策略，通过检索相似参考模因的标签信息为智能体提供显式先验信号。
**MIA (Meme Insight Augmentation)**：向内分析策略，通过收集智能体的错误推理轨迹并迭代提炼通用洞见知识。
**In-context Learning (ICL)**：上下文学习，通过在输入中直接拼接 few-shot 示例引导模型输出，无需更新参数。
**Chain-of-Thought (CoT)**：思维链提示技术，引导模型逐步推理并输出中间思考过程后再给出最终答案。
**Macro-F1**：宏观平均 F1 分数，各类别 F1 的算术平均，对类别不平衡数据集更能反映真实性能。
**Gradient-free**：无梯度，指不通过反向传播更新模型参数，而是通过推理流程和外部知识利用来完成学习。

## 可复现要素
- **数据集**：HarM、FHM、MAMI 均为公开数据集（HarM 来自 Pramanick et al., 2021；FHM 来自 Hateful Memes Challenge；MAMI 来自 SemEval-2022 Task 5）。
- **代码/权重**：论文声明"代码未在提交中包含，但将在论文接受后公开发布"；使用 LLaVA-34B（开源）和 GPT-4o（API 访问）。
- **关键超参**：参考集大小 N=50，检索 Top-K=5，α=0.2（视觉权重），β=0.8（文本权重），温度参数=0（greedy decoding），洞察集容量上限=10。
- **编码器**：CLIP ViT-L/14@336px。
- **评估协议**：5 个不同随机种子的 50-shot 参考集，取平均 Accuracy 和 Macro-F1。
